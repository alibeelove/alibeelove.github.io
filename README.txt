ALISON CAUCHI — ABSTRACT ART WEBSITE

CONTENTS
- index.html: complete one-page artist website
- styles.css: responsive visual design
- script.js: mobile navigation and current-year footer

HOW TO VIEW
1. Extract the ZIP file.
2. Open index.html in a web browser.

BEFORE PUBLISHING
1. Replace the sample abstract artwork graphics with photographs of Alison's actual paintings.
2. Replace hello@alisoncauchi.com in index.html with the preferred contact email.
3. Update artwork titles and descriptions to match the real collection.
4. Add prices, dimensions, shipping details and a secure checkout provider if you want direct online purchases. The current shop section invites customers to enquire; it does not process payments.
5. Connect a domain and hosting service, then upload the files.

This is a responsive static website starter. Google Fonts require an internet connection; system fonts are used as a fallback.
